# **Midterm - Module 8 - Bank Account Simulation**

**Project Title:** Module 8 - Lew Bank Terminal  

### **1\. Module Overview**

This module showcases several C++ programming concepts in a midterm project as a Bank Account Simulator. Using the BankAccount class, several functions (deposit, makePurchase, displayBalance, saveTransaction, showMenu), and user input, the user can simulate using a very basic Bank Account terminal.

### **2\. Functionality**

* The user can make deposits
* The user has 2 choices for purchases: coffee and book
* The user can choose to show Available Balance
* Transactions are recorded to transactions.txt
